# Sales Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive Sales Analytics Dashboard built using Microsoft Power BI to analyze sales performance, product trends, customer ratings, and payment methods.

## Key KPIs
- Total Sales
- Total Quantity
- Average Sales
- Total Transactions

## Dashboard Features
- Month-wise interactive filtering
- City-wise sales analysis using a map
- Brand-wise sales and quantity comparison
- Transaction analysis by payment method
- Customer ratings analysis
- Day-wise sales trends
- Mobile model-wise sales comparison

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Objective
To provide a clear overview of sales performance and help identify product trends, customer preferences, and business opportunities.
